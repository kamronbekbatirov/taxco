РАБОЧИЕ НАСТРОЙКИ:
═══════════════════════════════════════════════════════════════

• Рабочие дни: Понедельник - Пятница
• Время работы: 10:00 - 18:00
• Обед: 13:00 - 14:00
• Слот: 1 час

Чтобы изменить эти настройки, отредактируйте:
/var/www/taxco.uz/booking/config.php

Примеры изменений:

   Изменить время работы:
   define('WORK_START_HOUR', 9);   // начало в 9:00
   define('WORK_END_HOUR', 19);    // конец в 19:00

   Изменить обед:
   define('LUNCH_START_HOUR', 12); // обед с 12:00
   define('LUNCH_END_HOUR', 13);   // до 13:00

   Добавить субботу:
   $WORK_DAYS = [1, 2, 3, 4, 5, 6]; // 6 = суббота

Если email не приходят, проверьте:

1. Настроен ли sendmail:
   php -i | grep sendmail_path

2. Установите sendmail если нужно:
   sudo apt-get install sendmail
   sudo systemctl enable sendmail
   sudo systemctl start sendmail

3. Проверьте логи:
   sudo tail -f /var/log/mail.log

   php -v   (должна быть 8.0+)
